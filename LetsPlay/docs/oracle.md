# 即兴 Oracle（oracle 命令）

`talkdnd oracle` 是只给 DM 的即兴灵感工具：回答是/否问题、给一个事件焦点、给一个含义短语。它是**纯灵感**——不写任何存档文件、不参与规则结算、不伪造骰子（1d6 走 combat-sim 骰子引擎）、不引入书籍随机表。输出全部来自模块内置的原创短语表，与任何冒险内容无关。

## 命令

| 命令 | 参数 | 输出 |
|---|---|---|
| `oracle yes-no [<问题>]` | 问题可省略，不回显 | 只打印 `yes` 或 `no`（掷 1d6：1–3 yes，4–6 no） |
| `oracle event [--focus F]` | F 为可选焦点词 | 一个事件焦点短语；有非空 focus 时打印 `<focus>：<短语>` |
| `oracle meaning [--chaos 1-9]` | 默认 5 | `<含义短语>（混乱 <N>）`；chaos 只接受 1–9 |

- **只读**：不改 progress/canon/reveals/original/save-meta、不写 rolls.log 或会话日志、不创建任何文件，任何时候都可以放心跑。
- **骰子只经程序**：yes-no 的 1d6 由 combat-sim 骰子引擎掷出；全局隐藏参数 `--seed` 仅供测试复现（同一 seed 输出完全一致），正式游戏不要用。
- **只出点子，不定事实**：输出要不要采用、怎么引入，由 DM 决定。它不能登记原创内容、也不能绕过剧本偏离度（scope 0 时它给的点子只能当「补空白」材料）；确要引入原创内容，仍走 `original add` 的台账与预算流程（见 `docs/deviation.md`）。
- **混乱值（chaos 1–9）**：只是 DM 对「当前局势有多不可预测」的自行标注，数字越大越混乱；程序不解释、不记忆这个数字。

## dm-plan 模板

`talkdnd original plan` 在 `Saves/<存档>/dm-plan.md` 不存在时创建模板（DM-only、已 gitignore、不提交），除 `## 计划` 与 `## 伏笔与回收` 外包含六个可选小节，按需填写：

- `## 当前局面`
- `## 参与者目标`
- `## 冲突`
- `## 线索`
- `## 可能行动`
- `## 不介入后果`

模板只在文件不存在时创建；已经写过的 dm-plan.md 绝不会被覆盖或改写。秘密词标记（`- term: X`、`[[X]]`）的收集规则见 `docs/narration.md`。
