# 战斗核心动作（v1.5a）

本页给 DM 使用：擒抱、推撞、徒手打击、双武器战斗与额外攻击。规则参数按存档的 edition 从 `Rules/combat/` 读取；2014 与 2024 不混用。命令都在游戏文件夹里运行，`CS=bin/combat-sim`（Windows：`bin\combat-sim.exe`）。

## 先看 ruleset

| 动作 | 2014（5e） | 2024（5.5e） |
|------|------------|--------------|
| 擒抱 | 攻击动作中的一次攻击；运动检定对抗目标运动或特技（目标选） | 徒手打击选项；目标力量或敏捷豁免，DC = 8 + 力量调整 + 熟练 |
| 推撞 | 攻击动作中的一次攻击；运动对抗目标运动或特技；成功击倒或推开 5 尺 | 徒手打击选项；目标力量或敏捷豁免；成功击倒或推开 5 尺 |
| 徒手打击 | 1 + 力量调整（非负）钝击 | 1d3 + 力量调整钝击 |
| 双武器 | 主手轻近战武器后，附赠动作以另一只手的轻近战武器攻击；伤害不加正的能力调整 | 同上 |
| 额外攻击 | 由生物/被动特性的 `extra_attacks` 数据决定 | 同上 |

目标最多只能比攻击者大一个体型等级。免疫对应条件的目标不能被该动作影响。

## 攻击动作预算

- 有额外攻击的生物：`grapple` 或 `shove` 只消耗攻击动作中的一次攻击；随后用 `attack`/`attack --unarmed` 继续结算剩余攻击。默认 `attack` 会结算全部剩余攻击；加 `--one` 只结算一次，保留剩余次数给之后的攻击、擒抱或推撞。例如额外攻击 2 次的战士可以先 `attack --one` 用长剑砍一次，再擒抱，最后再攻击一次。
- 只有一次攻击的生物：擒抱/推撞用掉整个攻击动作，本回合不能再攻击或再擒抱；`--one` 与普通攻击等价。
- `--offhand` 只用附赠动作，不占攻击次数；`--multi` 和 `use` 是整个动作，不能与尚未完成的攻击动作混用。`--one` 不能与 `--offhand` 或 `--multi` 同时使用。
- 回合开始时自动清空预算并重置动作；不需要手动记录。失败或非法尝试不会额外消耗攻击次数。

## 常用命令

```text
$CS grapple <攻击者> <目标>
$CS grapple <攻击者> <目标> --defense athletics
$CS shove <攻击者> <目标>
$CS shove <攻击者> <目标> --mode away
$CS attack <攻击者> <目标> --unarmed
$CS attack <攻击者> <目标> --unarmed --nonlethal
$CS attack <攻击者> <目标> <武器> --one
$CS attack <攻击者> <目标> --unarmed --one
$CS attack <攻击者> <目标> <轻近战武器> --offhand
$CS attack <攻击者> <目标> <武器>
```

- 2014 的 `--defense` 用 `athletics` 或 `acrobatics`；2024 用 `str` 或 `dex`。不写时目标自动选最高的一项，日志会说明；写了非法值会在消耗动作前报错。
- `shove --mode knock-down` 给目标 `prone`；`--mode away` 推开 5 尺，走强制移动路径，不消耗速度、不引发借机攻击，遇墙/占位/边界会停下并说明原因。
- `--offhand` 必须先用轻近战武器执行过攻击动作；主手与副手必须是不同的轻近战武器，且本回合附赠动作未用。失败不会消耗附赠动作。
- `--unarmed` 不套用武器属性或精通；`--nonlethal` 在近战把目标打到 0 HP 时改为击倒。
- `attack` 会按剩余攻击次数连续结算；目标倒下后剩余攻击跳过并记录。`--offhand`、`use` 和怪物 `--multi` 不会触发额外攻击。

## 日志与裁定

- 日志会给出动作、检定/豁免、DC 或对抗总值、条件、位移与资源消耗；失败也会说明原因。
- 目标免疫、体型过大、不在触及/视线内、没有轻武器、附赠动作已用、没有剩余攻击次数等情况会直接报错或记录并停止，不会消耗错误资源。
- 被擒抱的目标速度 0；2024 还记录擒抱者，攻击擒抱者以外的目标有劣势。挣脱按对应版本处理：2014 用动作对抗，2024 用动作对擒抱 DC 做运动或特技检定。
- 动作只能在角色自己的回合使用；准备动作或 DM 裁定需要在命令后加 `--force`，日志会留下审计警告。
- 不要把 `dm-secrets.md`、存档正文或规则书原文写进命令输出或公开记录。
