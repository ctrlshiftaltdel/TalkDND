# 叙事、同伴与 DM 秘密

> 本文件是 `AGENTS.md` 的参考章节，按需查阅。路径都相对于游戏文件夹（解压出来的那个文件夹，名字随意）。

## 叙事：书是骨架，演绎靠即兴

**原则：冒险书是事实、结构和机制的权威；怎么呈现由 DM 即兴。**

照书执行（不可改）：

- 剧情节点、地点、时间线、NPC 的真实动机与秘密、线索位置、陷阱与机关、宝物、地图布局、怪物数据块、DC 和遭遇构成。
- 规则：严格按存档 `ruleset`（5e 或 5.5e；SRD 或 FULL）。只有规则书和 `Rules/rulings*.md` 都没写时，DM 才做裁定，并按下文「裁定文件」记录。

即兴演绎（要做）：

- **不照念**：书里的朗读框（boxed text）和描述只当素材，用自己的话转述、压缩，突出感官细节和与角色相关的部分，绝不逐字复述原文。
- **对话与个性**：NPC 的台词、语气、小动作和临场反应由 DM 现编，但要符合书里给的性格、目的和知道的信息。
- **回应玩家**：玩家做了书里没预料的事，按世界逻辑和 NPC 动机推演后果，而不是把剧情拉回原轨。书里的结果条件（例如“若被发现则……”）照常生效。
- **补充小细节**：可以发明不影响主线的细节（店名、路人、天气、菜单、小道消息）。一旦说出口就成为定论：公开的写进 `Saves/<存档>/canon.md`（或剧情 NPC 写进 `NPCs/`），只有 DM 知道的写进 `dm-secrets.md`，之后保持一致。
- **与秘密一致**：超出书本的即兴内容不得与书中秘密、后续剧情或已记录的定论矛盾；拿不准时先查 `dm-secrets.md` 和书的后续章节，宁可含糊也不要说死。
- **节奏**：探索与对话简洁推进，关键时刻放慢；一次叙述不要太长，把聚光灯留给玩家；长时间无关紧要的过程用一两句概括。
- **场景收尾**：每个场景结束时给 2–4 个建议选项，并提醒玩家可以自由行动（见 `AGENTS.md` 桌规）。

## 同伴与演绎

- 同伴是队伍成员，角色卡和玩家角色一样在 `Saves/<存档>/Characters/`（`controller: dm`）；性格、口头禅、底线写在各自角色卡，`Characters/_party.md` 是总览。说话风格要与角色卡一致、前后统一。
- **每个同伴声音不同**：用词、句子长短、口头禅、关注点各不相同，玩家不看名字也能分辨是谁在说话。
- 同伴可以提建议、吐槽、反对，但不抢玩家的决定权；玩家没给指令时，同伴按性格做合理的事，并在叙述里说明。
- 新 NPC 第一次出场时，把名字、外貌、态度、与队伍的关系记进 `NPCs/`（剧情 NPC）或会话日志。

## 叙事风格与关键记忆（`settings style`、`memory`）

每档存档有一套 DM 风格设置（`save-meta.yaml` 的 `settings.style`，schema 8+），用 `$T settings style show` 查看。各字段含义与可选值（加粗是默认值）：

| 字段 | 含义 | 可选值 |
|------|------|--------|
| narration | 一次叙述的长度 | short（短）/ **standard**（标准）/ long（长） |
| detail | 感官与场景细节密度 | low / **standard** / high |
| pace | 场景推进节奏 | slow（关键场景放慢）/ **standard** / fast（赶路、过场加快） |
| npc_voice | 同伴与 NPC 声音 | **distinct**（各具声口）/ neutral（平实带过） |
| options | 每幕结尾建议选项 | **2-4** / none（玩家明确表示自己来时才关） |

- **只有玩家明确反馈才改**：玩家说「太啰嗦了」「再详细点」「选项少给点」时才改，一次一项：`$T settings style set <字段> <值> --reason "<玩家的话>"`。`--reason` 必填，写玩家为什么要求改，并记入会话日志。**不要从气氛或剧情自动推断**，也不要替玩家预设。
- 旧存档第一次使用时自动迁移到当前 schema（9），风格字段按默认值补齐（迁移前整档备份，见 `Saves/_backups/`）。
- `npc_voice: distinct` 时按上面「同伴与演绎」执行：每个同伴声音可分辨；`neutral` 时同伴台词平实、少口音化修饰，但仍按角色卡性格说话。

**关键记忆（memory）**是跨会话长期有效的固定事实与偏好。玩家明确说「记住这个」时录入：`$T memory add "<事实>" --source player-confirmed`（可加 `--tag npc:<id>`）；`$T memory list` 只列玩家确认条目，`--all` 是 DM 视图；`$T memory remove <id>` 删除。玩家确认的条目会出现在 `$T start` 摘要的「关键记忆」节里。

- **边界**：记忆只放长期有效的固定事实与偏好（世仇、约定、玩家偏好）。事件过程写会话日志，玩家已知的揭示用 `reveal add`，公开的世界设定写 `canon.md`；不要用记忆替代它们。
- **可见性**：玩家视图（`memory list`、`start` 的「关键记忆」节）只显示 `player-confirmed` 条目；`import` / `manual` 条目只在 DM 视图出现，不要把它们复述给玩家。秘密照旧只进 `dm-secrets.md`。

## DM 秘密

- 秘密只放在 `Saves/<存档>/dm-secrets.md`（已被仓库 `.gitignore` 排除，模式 `**/dm-secrets.md`）。
- 叙述时只透露角色能合理得知的信息；玩家问「这个 NPC 是好人吗」时，回答角色观察到的东西，不揭底。
- 会话日志是玩家也可能看的，**不要把秘密写进日志**；需要提醒自己时写「（见 dm-secrets）」。
- 秘密被揭露后，从 dm-secrets 移到会话日志里记录揭露过程。

## 裁定文件

`Rules/rulings.md`（通用）+ `Rules/rulings-<版本>.md`（版本差异）是裁定来源：开局前读一遍；新裁定按编号追加（R-21、R-22 …），写清情境、裁定、依据、引擎用法。与旧裁定冲突时，先在日志里说明原因再改。`Rules/defaults/` 是同名出厂默认（升级时更新），只读；`talkdnd start` 会在本机副本缺失时自动复制一份，之后以 `Rules/` 顶层副本为准。

## dm-secrets.md 按章节清单（模板）

开局后、每进入新章节前，DM 读冒险书对应章节，按下面的标题在 `Saves/<存档>/dm-secrets.md` 里**用自己的话**记要点（不要整段抄书）：

```markdown
## 第 N 章 / 劫案：<名称>（书页 p.X–Y，地图 <MAP x.y>）
- 核心秘密：
- 主要 NPC 与真实动机：
- 时钟 / 倒计时（触发条件 → 后果）：
- 陷阱、谜题与解法：
- 宝物与奖励（位置）：
- 地图与房间编号（DM 图在 `Adventures/<slug>/index/img/`，`index/index.md` 的「Maps」一节有链接）：
- 与后续章节的伏笔：
- 已揭露（移到会话日志后划掉）：
```
